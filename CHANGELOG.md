# Changelog

All notable changes to RESTIO are documented here.

## [2026.12.2] - 2026-12-02

### Added

- Added a delivery queue for collecting multiple canvas formats and exporting them as a ZIP package with a specification manifest.
- Added a resolution and print calculator for scaled pixel output and physical-size conversions.
- Added aspect-ratio comparison previews for checking alternate crops.
- Added composition guides with centerlines, thirds, golden-ratio, and configurable safe-area overlays.
- Added a command palette with keyboard shortcuts for common workbench actions.
- Added SVG, JPEG, and WebP export options alongside PNG export.

### Improved

- Updated the bundled interface to the 2026.12.2 design and interaction pass.
- Improved responsive workbench, library, and touch-device layouts.
- Added persistent queue, project, guide, and export preferences through local storage.
- Bundled utility and icon styles so the core interface loads without external style dependencies.
